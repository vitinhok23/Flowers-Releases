# Flowers-Releases

Downloads oficiais do **FLOWERS** para Windows 10/11 x64.

- [Baixar instalador](https://github.com/vitinhok23/Flowers-Releases/releases/latest/download/FLOWERS.Desktop-win-Setup.exe)
- [Baixar versão portátil](https://github.com/vitinhok23/Flowers-Releases/releases/latest/download/FLOWERS.Desktop-win-Portable.zip)
- [Ver versões e novidades](https://github.com/vitinhok23/Flowers-Releases/releases)

## Atualizar pelo painel

Use o instalador ou extraia o pacote portátil completo na primeira vez. Depois, acesse **Preferências → Atualizações do FLOWERS** para verificar, baixar e reiniciar com a nova versão.

Configurações e backups ficam preservados em uma pasta separada. Requer Microsoft Edge WebView2 Runtime.
